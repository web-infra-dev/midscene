# 排行榜筛选功能需求

## 背景

排行榜里的车型比较多，希望用户可以通过榜单切换和组合筛选，更快找到自己关心的车型。本期只处理排行榜页的筛选体验，不涉及车型详情、关注、收藏等功能。

## 核心需求

- 支持在销量榜、降价榜和新能源榜之间切换。
- 支持按车型、时间、能源类型和价格筛选；销量榜和新能源榜使用榜单时间，降价榜使用上市时间。
- 车型主要包括轿车、SUV、MPV；能源类型包括新能源、燃油车、纯电动、插电式混动；时间支持月度、近半年和近一年等常用范围。
- 价格既可以选择常用价位，也可以输入自定义范围。
- 同一类筛选条件单选，不同类条件可以组合使用。
- 已生效的条件要有清楚的选中或回显状态，结果列表要随条件更新。
- 切换榜单后，筛选条件应回到新榜单合理的初始状态，不能残留上一个榜单的条件。

## 重点验收场景

1. 在销量榜组合使用车型、时间、能源和价格筛选，确认条件正确生效。
2. 在销量榜筛选 SUV 和插电式混动车型，确认榜单结果可正常查看。
3. 在新能源榜查看近半年的纯电 SUV，并选择一个常用价位。
4. 在降价榜查看近一年上市的新能源 MPV，并设置自定义价格范围。
5. 设置多项条件后切换榜单，确认旧条件不会错误保留，并能在新榜单重新建立筛选组合。

## 验收要求

- 页面能清楚反映当前选择的条件。
- 榜单结果可以正常加载和查看。
- 榜单切换和条件组合行为符合预期。
