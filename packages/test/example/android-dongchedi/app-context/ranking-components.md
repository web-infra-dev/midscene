# 排行榜页面组件使用 Context

## 页面结构

- 页面上方可以切换“销量榜”“降价榜”和“新能源榜”等榜单。
- 页面中部是车型、时间、能源类型和价格等筛选项，下方是随筛选条件更新的结果列表。
- 销量榜和新能源榜使用榜单时间；降价榜使用上市时间。
- 同一类筛选条件单选，不同类条件可以组合使用。已生效的条件会显示选中或回显状态。
- 切换榜单后，筛选条件会恢复到新榜单自身的初始状态，不应继续沿用上一个榜单的条件。

## 常规筛选

- 打开对应筛选项后，按选项文案选择车型、时间或能源类型。
- 完成一组筛选后，应同时检查筛选项的选中或回显状态，以及下方结果列表是否正常更新。
- 不要通过固定坐标、选项序号或某次运行的滑动距离描述筛选项。

## 价格筛选

- 常用价位属于预设选项，点击后直接应用。
- 自定义价格需要在价格面板中分别调整最低价和最高价。调整后仍处于待确认状态，点击面板底部的结果按钮后才会真正应用并更新列表。
- 应以价格面板或筛选栏显示的完整价格文案判断实际范围，不要根据滑块位置猜测数值。
- 初始上下限位于屏幕两侧。Android 屏幕边缘可能触发系统返回手势，不要依赖从边缘开始的固定拖动轨迹。
- 目标值已有刻度时优先点击刻度。需要同时设置上下限时，可以先把上限移到内部刻度，再设置下限，最后核对完整价格文案并点击结果按钮。
