# 懂车帝页面跳转 Context

## 首页

- 上方快捷入口区域有“排行榜”入口，点击后进入排行榜页面。
- 中间有搜索框，点击后进入搜索页面。
- 下方是可以持续滚动的帖子列表。
- 底部固定导航栏包含“首页”“选车”“AI”“消息”“我的”五个 Tab。

## 排行榜页面

- 从首页的“排行榜”入口进入。
- 页面上方用于切换榜单，中部用于设置筛选，下方展示在榜车型列表。
- 点击结果列表中的车型可以进入对应的车型详情页。

### 重置排行榜页面状态

- 先退出排行榜页面回到首页，再点击首页上方快捷入口中的“排行榜”重新进入。
- 重新进入后，榜单和筛选会恢复初始状态。完成重置后停留在排行榜页面。

## 车型详情页

- 页面展示当前车型名称。
- 页面右上角的心形按钮用于关注或取消关注当前车型。

## 我的页面

- 通过底部导航栏的“我的”Tab 进入。
- 页面顶部展示用户信息，中部有“关注订阅”和“收藏”等入口，下方是其他功能与活动列表。
- 点击“关注订阅”进入关注订阅页面。

## 关注订阅页面

- 页面包含“关注”和“订阅”Tab。
- “关注”Tab 下可以在用户和汽车之间切换；汽车列表展示已经关注的车型。
