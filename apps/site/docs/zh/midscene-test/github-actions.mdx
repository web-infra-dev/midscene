# 在 GitHub Actions 中运行

Midscene 提供了 [midscene-action](https://github.com/marketplace/actions/midscene-action)，用于在 GitHub Actions 中运行 Midscene Test。

- 自动将测试结果汇总到工作流的 **Summary**。
- 将 HTML 报告和测试数据保存为 **Artifacts**，供下载查看。
- 按需将报告发布到 **Cloudflare Workers**，通过链接在线预览。

尚未创建测试项目时，请先阅读[创建和使用测试项目](./use)。

接入步骤、配置参数和完整示例，请参阅 [GitHub Marketplace 上的 midscene-action](https://github.com/marketplace/actions/midscene-action)。
