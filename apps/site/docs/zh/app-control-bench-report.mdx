# Midscene AppControlBench Benchmark 测试报告

import { AppControlBenchReport } from '@theme';

本报告展示 Midscene 在 AppControlBench 上的测试结果。本次评测包含 60 个 iOS 任务，**Pass@1 为 96.67%。** 完整运行记录的模型总成本为 **$0.6382 / ¥4.3399**。

:::info 关于 AppControlBench

[AppControlBench](https://github.com/software-mansion/app-control-bench) 用于评估 Agent 操作真实 iOS 应用的能力。每个任务都在隔离的 Simulator 中运行；任务结束后，根据任务专属的目标界面描述对最终截图进行评分。本次运行包含 30 个 Bluesky 任务和 30 个 Element iOS 任务。

:::

## Case 意图校准

本次评测针对固定版本 Element iOS 的实际界面，对 2 个 case 的操作路径描述进行了校准。校准只消除旧版或不存在的 UI 入口描述，不改变 case 的最终目标状态和 judge 规则。

| Case | Before | After | 变更理由 |
| --- | --- | --- | --- |
| `element-06` | Open the create-room menu (the + button) in the messenger. | Open the create/compose menu in the messenger. | 固定版本 Element iOS 已不再提供旧版 “+ button” 入口；仅校准操作路径，目标状态和 judge 规则不变。 |
| `element-07` | Open the "Project Phoenix" room and open its room-options menu (the '...' in the header). | Open the "Project Phoenix" room info/options screen. | 固定版本 Element iOS 不存在 header `...` 入口；仅校准操作路径，目标状态和 judge 规则不变。 |
