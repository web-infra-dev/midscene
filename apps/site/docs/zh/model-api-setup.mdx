# 使用模型 API Key

本文介绍如何使用模型服务商提供的 API Key 接入 Midscene，包括完成配置和验证连接。如果你已有 ChatGPT 订阅，也可以参考[使用 ChatGPT 订阅](./chatgpt-subscription)文档中的描述操作。

本页列出的模型配置，本质上都是环境变量。你可以根据使用方式提供这些配置：

- 使用 Playground 时，在设置页面直接粘贴本页的配置文本。
- 使用 SDK 或命令行工具时，按照[设置环境变量](#设置环境变量)中的说明加载配置。

如需查询高级配置参数，请阅读[模型高级配置与调试](./model-config)。

## 支持的模型

模型选型建议和接入方式见[模型选择指南](./model-selection)。下面提供各模型的配置示例。

每份配置都需要 Base URL、API Key、模型名称和 `MIDSCENE_MODEL_FAMILY`。`MIDSCENE_MODEL_FAMILY` 选择模型适配器，决定坐标处理方式、支持的 API 协议，以及思考和输出参数的发送方式。请使用下方对应模型列出的 family 值。

**使用 API Key**

环境变量配置示例，以 `gpt-6-sol` 为例：

<ModelConfigCard
  baseUrl={{
    value: "https://api.openai.com/v1",
    comment: "OpenAI API 地址；或你的兼容服务地址",

  modelFamily="gpt-6"

**开启 Fast mode（`service_tier="fast"`）**

GPT-5.6 Sol 和 GPT-6 Astra 均支持 Fast mode，可以追加 `service_tier` 请求体参数启用，以 GPT-5.6 Sol 为例：

```bash
MIDSCENE_MODEL_NAME="gpt-5.6-sol"
MIDSCENE_MODEL_FAMILY="gpt-5"
MIDSCENE_MODEL_EXTRA_BODY_JSON='{"service_tier":"fast"}'
```

按照 OpenAI 官方说明，Fast mode 可获得最高 2～2.5 倍的速度，费率为 Standard 费率的两倍。具体速度、价格和使用限制以[官方说明](https://developers.openai.com/api/docs/guides/fast-mode)为准。


如需复用 Codex CLI 登录，请参考[使用 Codex App Server](./chatgpt-subscription#use-codex-app-server-oauth-no-api-key)。

**使用 GPT 时，请注意以下事项：**

- 使用 GPT 做 UI 定位至少需要 GPT-5.4，Midscene 不支持更早的版本。
- 按照 OpenAI 的文档，GPT-5 在处理非拉丁字母文本、字号太小的文本时效果可能不理想，参见 [Images and Vision guide](https://developers.openai.com/api/docs/guides/images-vision)。
- OpenAI 在 computer use 文档中提到，他们观察到 `1440x900` 和 `1600x900` 这两种截图尺寸上通常能获得比较好的效果，详见 [Computer use guide](https://developers.openai.com/api/docs/guides/tools-computer-use)。因此，建议按照 OpenAI 的推荐对截图尺寸进行调整。在 Midscene 中，你可以通过 Agent 参数里的 `screenshotShrinkFactor` 控制截图压缩倍率。如果是浏览器自动化，还可以通过浏览器 `viewport` 指定页面的尺寸和比例。
- 使用 Azure OpenAI 的 Chat Completions API 时，`"detail": "original"` 可能未被正确处理，从而造成点击坐标偏移。遇到此问题时，可以切换到 Responses API。详见 [使用 Azure OpenAI 时点击坐标偏移](./faq#使用-azure-openai-时点击坐标偏移)。

</details>

### Jev（实验性） {#jev}

<details>
<summary>查看模型配置</summary>

Jev 是一个做选择的模型，可以用它选择下一步动作、定位界面元素，以及判断条件是否成立。它的优势是速度快、成本低，但不适用于需要复杂推理的任务。

Midscene 对 Jev 的支持是实验性的。

- 模型供应商：[TypeSafe](https://typesafe.ai/)

**先配置并保留一个通用模型的默认配置（`MIDSCENE_MODEL_*`），再追加下面的 Jev 配置。** Jev 用于 Planning、Locate 和 Insight，无法处理的任务仍由通用默认模型完成。默认模型的配置方式参见[多模型组合](./model-config#multi-model-combination-example)。

复制以下配置，将 Planning、Locate 和 Insight 配置为 Jev：

<ModelConfigCard
  baseUrl={{
    value: "https://api.typesafe.ai/v1",
    comment: "TypeSafe 官方 API 地址",
  }}
  modelName="jev-1.14.0"
  modelFamily="jev"
  layout="combined"
  purposes={['planning', 'locate', 'insight']}
/>

Jev 使用 TypeSafe 的 System One 协议，不使用 OpenAI 协议。OpenAI 的部分模型配置不适用于 Jev，包括温度、原生思考、响应格式和流式输出等。

:::info 图像输入限制

Jev 要求输入图像的最长边不超过 1568 像素，因此 Midscene 会对超出限制的图像进行等比缩放，并在定位后将结果映射回原图坐标。不足 280 像素的边会补白。该图像处理逻辑后续可能调整。

:::

</details>

## 设置环境变量

Midscene 从环境变量读取模型配置。请选择与你的使用方式对应的方法，也可以沿用项目已有的环境变量管理方式。

### 在当前 Shell 中设置环境变量

以下示例适用于 Bash 和 Zsh。变量只在当前 Shell 会话及其启动的子进程中有效。

```bash
# 将全部值替换为所选模型服务商提供的配置
export MIDSCENE_MODEL_BASE_URL="https://替换为你的模型服务地址/v1"
export MIDSCENE_MODEL_API_KEY="替换为你的 API Key"
export MIDSCENE_MODEL_NAME="替换为你的模型名称"
export MIDSCENE_MODEL_FAMILY="替换为你的模型对应的 family"
```

### 通过 `.env` 文件配置

Midscene Test（`@midscene/test`）和[旧版 YAML 脚本运行器](./yaml-script-runner)（`@midscene/cli`）会自动读取 `.env` 文件中的配置。

使用 Midscene Test 时，在生成的测试项目目录中将 `.env.example` 复制为 `.env`，填入模型配置后运行 `pnpm test`，详见[创建与使用测试项目](./midscene-test/use)。使用旧版 YAML 脚本运行器时，在运行 `midscene` 命令的目录中创建 `.env`。

`.env` 文件内容示例：

```bash
# 将全部值替换为所选模型服务商提供的配置
MIDSCENE_MODEL_BASE_URL="https://替换为你的模型服务地址/v1"
MIDSCENE_MODEL_API_KEY="替换为你的 API Key"
MIDSCENE_MODEL_NAME="替换为你的模型名称"
MIDSCENE_MODEL_FAMILY="替换为你的模型对应的 family"
```

`.env` 中的每一行都不需要添加 `export`。使用旧版 YAML 脚本运行器时，当前 Shell 中已有的同名变量默认优先于 `.env`；可通过 `--dotenv-override` 让文件中的值优先。

:::info JavaScript SDK

Midscene SDK 从 `process.env` 读取模型配置。编写测试脚本时，可以在自己的测试项目中安装 [dotenv](https://www.npmjs.com/package/dotenv)，将模型配置放入项目根目录的 `.env` 文件，并在脚本入口添加 `import 'dotenv/config'`，然后从项目根目录运行脚本。请在创建 Agent 前加载配置。

:::

## 其他兼容模型

以下小参数模型也与 Midscene 兼容，主要面向自动化场景。它们对部署硬件的要求较低，但处理复杂任务或大尺寸截图的能力可能受限。选择前，请结合实际任务和部署条件进行评估。

### 智谱 AutoGLM 系列 {#auto-glm}

<details>
<summary>查看模型配置</summary>

智谱 AutoGLM 是智谱 AI 推出的开源移动端 UI 自动化模型，模型尺寸为 9B。

从 [Z.AI（国际）](https://z.ai/manage-apikey/apikey-list) 或 [BigModel（国内）](https://bigmodel.cn/usercenter/proj-mgmt/apikeys) 获取 API Key 后，可以使用以下配置：

```bash
MIDSCENE_MODEL_BASE_URL="https://open.bigmodel.cn/api/paas/v4" # 或 https://api.z.ai/api/paas/v4
MIDSCENE_MODEL_API_KEY="......"
MIDSCENE_MODEL_NAME="autoglm-phone" # 模型名以平台实际模型名为准
MIDSCENE_MODEL_FAMILY="auto-glm" # 或 "auto-glm-multilingual"
```

**关于 `MIDSCENE_MODEL_FAMILY` 配置**

AutoGLM 提供了两个版本的模型，通过 `MIDSCENE_MODEL_FAMILY` 区分：

- `auto-glm` - 对应 AutoGLM-Phone-9B，针对**中文环境**优化
- `auto-glm-multilingual` - 对应 AutoGLM-Phone-9B-Multilingual，支持**英语等其他语言**场景

请根据你的应用语言选择合适的版本。

:::info
AutoGLM 更适合移动端交互。`aiAssert` 和 `aiQuery` 等 API 需要理解页面。使用这些 API 时，请通过 `MIDSCENE_INSIGHT_MODEL_...` 环境变量配置独立的 Insight 模型。详情请参考[模型选择指南](./model-selection)。
:::

**了解更多关于智谱 AutoGLM**

- GitHub: [https://github.com/zai-org/Open-AutoGLM](https://github.com/zai-org/Open-AutoGLM)
- Hugging Face: [https://huggingface.co/zai-org/AutoGLM-Phone-9B](https://huggingface.co/zai-org/AutoGLM-Phone-9B)

</details>

### UI-TARS 系列 {#ui-tars}

<details>
<summary>查看模型配置</summary>

你可以在 [火山引擎](https://volcengine.com) 上使用已部署的 `doubao-1.5-ui-tars`。

```bash
MIDSCENE_MODEL_BASE_URL="https://ark.cn-beijing.volces.com/api/v3"
MIDSCENE_MODEL_API_KEY="...."
MIDSCENE_MODEL_NAME="ep-2025..." # 来自火山引擎的推理接入点 ID 或模型名称
MIDSCENE_MODEL_FAMILY="vlm-ui-tars-doubao-1.5"
```

**关于 `MIDSCENE_MODEL_FAMILY` 配置**

`MIDSCENE_MODEL_FAMILY` 用于指定 UI-TARS 版本，使用以下值之一：

- `vlm-ui-tars`：用于模型版本 `1.0`
- `vlm-ui-tars-doubao`：用于在火山引擎上部署的模型版本 `1.5`（与 `vlm-ui-tars-doubao-1.5` 等效）
- `vlm-ui-tars-doubao-1.5`：用于在火山引擎上部署的模型版本 `1.5`

:::info

旧版本使用 `MIDSCENE_USE_VLM_UI_TARS=DOUBAO` 或 `MIDSCENE_USE_VLM_UI_TARS=1.5` 配置，该配置仍然兼容但已废弃，建议迁移到 `MIDSCENE_MODEL_FAMILY`。

迁移对应关系：

- `MIDSCENE_USE_VLM_UI_TARS=1.0` → `MIDSCENE_MODEL_FAMILY="vlm-ui-tars"`
- `MIDSCENE_USE_VLM_UI_TARS=1.5` → `MIDSCENE_MODEL_FAMILY="vlm-ui-tars-doubao-1.5"`
- `MIDSCENE_USE_VLM_UI_TARS=DOUBAO` → `MIDSCENE_MODEL_FAMILY="vlm-ui-tars-doubao"`

:::

</details>
