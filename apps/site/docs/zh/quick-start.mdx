# 快速体验 GUI Agent

通过 Chrome Extension，你可以在浏览器的 Playground 中体验 GUI Agent，无需搭建测试项目。本指南带你配置模型、执行一条自然语言指令、验证结果并查看执行过程。

如果你要直接编写 YAML 测试，可以前往 [Midscene Test](./midscene-test/use)。移动端和桌面端的 Playground 入口见[其他平台](#在其他平台使用-midscene)。

## 配置模型

使用 Chrome Extension 前，需要先准备一个具备 UI 定位能力的多模态模型。如果尚未确定模型或接入方式，请先阅读[模型选择指南](./model-selection)。

<SetupEnv />

如果使用 ChatGPT 订阅，请按照[使用 ChatGPT 订阅](./chatgpt-subscription)获取完整模型配置，再继续安装扩展。两种接入方式任选一种即可。

安装 Chrome Extension 后，将这组配置粘贴到设置中。

## 安装 Chrome Extension {#chrome-extension}

1. 点击下面的按钮，从 Chrome Web Store 安装 Midscene：

   <ChromeExtensionButton linkLabel="从 Chrome Web Store 安装 Midscene Chrome Extension" />

2. 在 Chrome 的扩展列表中打开 **Midscene**。浏览器右侧会出现 Midscene 侧边栏。
3. 点击侧边栏中的设置图标，将[配置模型](#配置模型)中的完整配置粘贴到设置页并保存。

## 执行操作并验证结果

打开 [TodoMVC 示例页面](https://todomvc.com/examples/react/dist/#/)，保持页面可见，在 Midscene 侧边栏中依次体验下面三类 API。

### 1. 执行一个目标（`aiAct`）

选择 `aiAct`，输入并运行：

```text
添加一个名为“体验 Midscene”的待办事项，然后将它标记为已完成。
```

Agent 会观察页面，找到输入框，添加待办事项并勾选它。执行结束后，你应当在页面中看到该事项处于已完成状态。

### 2. 检查结果（`aiAssert`）

选择 `aiAssert`，输入并运行：

```text
列表中存在名为“体验 Midscene”的待办事项，且它已被标记为完成。
```

条件成立时断言通过；不成立时，结果中会显示错误及模型返回的原因。

### 3. 提取数据（`aiQuery`，可选）

选择 `aiQuery`，输入并运行：

```text
列表中可见的待办事项，返回 {name: string, completed: boolean}[]。
```

结果会包含待办事项名称及其完成状态。你可以看到，同一个界面既能被操作，也能被检查和读取。

## 常见问题

<span id="chrome-extension-faq" />

<details>
<summary>是否可以手动安装 Chrome Extension？</summary>

如果无法访问 Chrome Web Store，可以从 [GitHub Releases 页面](https://github.com/web-infra-dev/midscene/releases) 下载安装包并手动安装。但这种方式无法获得自动更新。

</details>

<details>
<summary>运行失败，提示 `Cannot access a chrome-extension:// URL of different extension`</summary>

这通常由其他 Chrome Extension 与 Midscene 冲突引起。例如，其他 Chrome Extension 可能已经向页面注入 `<iframe />` 或 `<script />`。

按照以下步骤查找发生冲突的 Chrome Extension：

1. 打开页面的开发者工具，找到 URL 以 `chrome-extension://` 开头的 `<iframe />` 或 `<script />`，并复制 URL 中的扩展 ID。
2. 打开 `chrome://extensions/`，根据扩展 ID 找到并禁用对应的 Chrome Extension。
3. 刷新页面并重试。

</details>

<details>
<summary>使用 Ollama 模型时出现 403 错误</summary>

设置环境变量 `OLLAMA_ORIGINS="*"`，允许 Chrome Extension 访问 Ollama 模型。

</details>
