<GetStartedStep id="test-configure">

## 验证模型并完成配置

运行以下命令，检查模型能否连通、是否与 Midscene 兼容。该命令只读取当前目录下的 `.env`，不需要浏览器或设备：

```bash
pnpm exec midscene-test model verify
```

如果验证失败，请参阅[验证模型连接](../model-config#verify-model-connectivity)。

<GetStartedWhen platform="web">

为 Playwright 安装 Chromium：

```bash
pnpm exec playwright install chromium
```

</GetStartedWhen>

<GetStartedWhen platform="android">

如果连接了多台设备，请在 `.env` 中将 `ANDROID_DEVICE_ID` 设置为 `adb devices -l` 输出中的设备 ID。

</GetStartedWhen>

<GetStartedWhen platform="ios">

项目默认连接 `localhost:8100` 上的 WDA。如需使用其他地址，请在 `.env` 中设置 `WDA_HOST` 和 `WDA_PORT`；通过网关访问时设置 `WDA_BASE_URL`。

</GetStartedWhen>

<GetStartedWhen platform="harmonyos">

如果连接了多台设备，请在 `.env` 中将 `HARMONY_DEVICE_ID` 设置为 `hdc list targets` 输出中的设备 ID。如果 `hdc` 不在 `PATH` 中，请设置 `HDC_HOME`。

</GetStartedWhen>

<GetStartedWhen platform="desktop">

如需控制主显示器以外的显示器，请在 `.env` 中设置 `COMPUTER_DISPLAY_ID`。在无界面 Linux 环境中，还需设置 `MIDSCENE_COMPUTER_HEADLESS_LINUX=true`。

</GetStartedWhen>

</GetStartedStep>

<GetStartedStep id="test-run">

## 运行示例并查看报告

<GetStartedWhen platform="web">

示例会在 Chromium 中打开 React TodoMVC，预置三条待办事项，然后通过 `aiAct` 和 `aiAssert` 修改并检查它们。

</GetStartedWhen>

<GetStartedWhen platform={['android', 'ios', 'harmonyos']}>

示例会在设备浏览器中打开 React TodoMVC，并先检查列表为空。请保持设备解锁。如果列表中留有之前运行产生的待办事项，请切换到 **All** 并删除全部事项（包括已完成的事项）。

</GetStartedWhen>

<GetStartedWhen platform="desktop">

示例会在目标显示器的浏览器中打开 React TodoMVC，并先检查列表为空。运行期间请勿移动鼠标或操作键盘。如果列表中留有之前运行产生的待办事项，请切换到 **All** 并删除全部事项（包括已完成的事项）。

</GetStartedWhen>

```bash
pnpm test
```

终端会输出测试结果和 `Report:` 报告路径。打开 HTML 报告，选择用例和步骤即可查看截图、输入输出和错误信息。报告默认保存在 `midscene_run/report/` 目录下。

用例通过即表示模型、运行环境和项目都已正常工作。运行参数请参阅[运行测试](../midscene-test/running)。

</GetStartedStep>

<GetStartedWhen scene="test" platform={['android', 'ios', 'harmonyos']}>

- **测试自己的应用**：在 `cases/todo.yaml` 中，将 `beforeEach` 里的 TodoMVC 初始化步骤替换为打开应用的 `launch` Node：

  ```yaml
  beforeEach:
    - launch: com.example.app

  cases:
    - name: 打开首页
      steps:
        - aiAssert: 应用首页已显示
  ```

  Android 使用包名，iOS 使用 Bundle ID，HarmonyOS 使用 bundle name。其他系统操作请参阅[各平台预置 Node](../midscene-test/builtin-nodes)。

</GetStartedWhen>
