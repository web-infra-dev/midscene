| 能力分类 | 代表方法 | 说明 |
| --- | --- | --- |
| 自动规划 | `aiAct` | 用自然语言描述目标，由 Agent 自动规划并执行多步操作。 |
| 即时交互 | `aiTap`、`aiInput` | 根据描述定位目标元素并执行单步指定操作，不进行多步规划。 |
| 数据提取 | `aiQuery`、`aiString`、`aiNumber`、`aiBoolean` | 从当前界面提取结构化或基础类型数据，供后续代码处理。 |
| 界面断言 | `aiAssert` | 校验当前界面是否符合预期；若不符合则抛出错误。 |
| 条件等待 | `aiWaitFor` | 等待界面出现预期状态；若超时仍未满足则抛出错误。 |

在实际使用时，通常先用 `aiAct` 或即时交互方法完成操作，再用 `aiAssert` 校验界面结果（操作执行完毕并不代表业务预期一定成立）。各方法的详细参数与返回值请参阅 [Agent API 参考](/zh/reference/#interaction-methods)。
