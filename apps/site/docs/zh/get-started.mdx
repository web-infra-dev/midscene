# 开始使用 {#get-started}

第一次运行 Midscene 前，需要确定三件事：目标浏览器或设备、使用 Midscene 的方式，以及使用的模型。回答下面的问题后，页面会列出对应组合的步骤。无论选择哪种组合，最后都会执行一次操作和一次断言，并可以在结果中查看执行过程。

页面地址会记录你的选择，你可以收藏该地址或分享给其他人。

1. 从 Chrome Web Store 安装 Midscene：

<GetStartedStep id="test-configure">

## 配置项目

将 `.env.example` 复制为 `.env`：

```bash
cp .env.example .env
```

<GetStartedWhen model="api-key">

用准备好的配置填写四项 `MIDSCENE_MODEL_*` 变量。

</GetStartedWhen>

<GetStartedWhen model="chatgpt">

`MIDSCENE_MODEL_BASE_URL` 和 `MIDSCENE_MODEL_API_KEY` 留空。设置 `MIDSCENE_MODEL_NAME` 和 `MIDSCENE_MODEL_FAMILY`，并添加 `MIDSCENE_MODEL_AUTH_MODE`：

```bash
MIDSCENE_MODEL_AUTH_MODE="siwc"
MIDSCENE_MODEL_NAME="gpt-6-sol"
MIDSCENE_MODEL_FAMILY="gpt-6"
```

</GetStartedWhen>

运行以下命令，检查模型能否连通、是否与 Midscene 兼容。该命令只读取当前目录下的 `.env`，不需要浏览器或设备：

```bash
pnpm exec midscene-test model verify
```

如果验证失败，请参阅[验证模型连接](./model-config#verify-model-connectivity)。

<GetStartedWhen platform="web">

为 Playwright 安装 Chromium：

```bash
pnpm exec playwright install chromium
```

</GetStartedWhen>

<GetStartedWhen platform="android">

如果连接了多台设备，请在 `.env` 中将 `ANDROID_DEVICE_ID` 设置为 `adb devices -l` 输出中的设备 ID。

</GetStartedWhen>

<GetStartedWhen platform="ios">

项目默认连接 `localhost:8100` 上的 WDA。如需使用其他地址，请在 `.env` 中设置 `WDA_HOST` 和 `WDA_PORT`；通过网关访问时设置 `WDA_BASE_URL`。

</GetStartedWhen>

<GetStartedWhen platform="harmonyos">

如果连接了多台设备，请在 `.env` 中将 `HARMONY_DEVICE_ID` 设置为 `hdc list targets` 输出中的设备 ID。如果 `hdc` 不在 `PATH` 中，请设置 `HDC_HOME`。

</GetStartedWhen>

<GetStartedWhen platform="desktop">

如需控制主显示器以外的显示器，请在 `.env` 中设置 `COMPUTER_DISPLAY_ID`。在无界面 Linux 环境中，还需设置 `MIDSCENE_COMPUTER_HEADLESS_LINUX=true`。

</GetStartedWhen>

</GetStartedStep>

<GetStartedStep id="test-run">

## 运行示例并查看报告

<GetStartedWhen platform="web">

示例会在 Chromium 中打开 React TodoMVC，预置三条待办事项，然后通过 `aiAct` 和 `aiAssert` 修改并检查它们。

</GetStartedWhen>

<GetStartedWhen platform={['android', 'ios', 'harmonyos']}>

示例会在设备浏览器中打开 React TodoMVC，并先检查列表为空。请保持设备解锁。如果列表中留有之前运行产生的待办事项，请切换到 **All** 并删除全部事项（包括已完成的事项）。

</GetStartedWhen>

<GetStartedWhen platform="desktop">

示例会在目标显示器的浏览器中打开 React TodoMVC，并先检查列表为空。运行期间请勿移动鼠标或操作键盘。如果列表中留有之前运行产生的待办事项，请切换到 **All** 并删除全部事项（包括已完成的事项）。

</GetStartedWhen>

```bash
pnpm test
```

终端会输出测试结果和 `Report:` 报告路径。打开 HTML 报告，选择用例和步骤即可查看截图、输入输出和错误信息。报告默认保存在 `midscene_run/report/` 目录下。

用例通过即表示模型、运行环境和项目都已正常工作。运行参数请参阅[运行测试](./midscene-test/running)。

</GetStartedStep>

<GetStartedStep id="sdk-integrate">

## 编写并运行第一个测试

<GetStartedWhen model="api-key">

在项目目录中，把准备好的四项配置写入 `.env` 文件。如果还没有项目，请先创建一个空目录。

</GetStartedWhen>

<GetStartedWhen model="chatgpt">

在项目目录中，把以下配置写入 `.env` 文件。如果还没有项目，请先创建一个空目录。

```bash
MIDSCENE_MODEL_AUTH_MODE="siwc"
MIDSCENE_MODEL_NAME="gpt-6-sol"
MIDSCENE_MODEL_FAMILY="gpt-6"
```

</GetStartedWhen>

在同一目录中运行以下命令验证配置：

```bash
pnpm dlx @midscene/test@latest model verify
```

<GetStartedWhen platform="web">

然后按照[接入 Playwright Test](./integrate-with-playwright)安装依赖、创建 fixture 并编写测试。该指南最后会运行测试并打开报告。

</GetStartedWhen>

<GetStartedWhen platform={['android', 'ios', 'harmonyos', 'desktop']}>

然后按照[接入 Vitest](./sdk/vitest)操作，并在其中的平台选择器中选择相同的平台。该指南最后会运行测试并打开报告。

</GetStartedWhen>

</GetStartedStep>

<GetStartedStep id="next-steps">

## 下一步

<GetStartedWhen scene="test" platform="web">

- **测试自己的网站**：在 `cases/todo.yaml` 中，将 `beforeEach` 里的 TodoMVC 初始化步骤替换为打开你的 URL 的 `gotoUrl` Node，再用 `aiAct` 和 `aiAssert` 描述步骤。请参阅[各平台预置 Node](./midscene-test/builtin-nodes)。

</GetStartedWhen>

<GetStartedWhen scene="test" platform={['android', 'ios', 'harmonyos']}>

- **测试自己的应用**：在 `cases/todo.yaml` 中，将 `beforeEach` 里的 TodoMVC 初始化步骤替换为打开应用的 `launch` Node：

  ```yaml
  beforeEach:
    - launch: com.example.app

  cases:
    - name: 打开首页
      steps:
        - aiAssert: 应用首页已显示
  ```

  Android 使用包名，iOS 使用 Bundle ID，HarmonyOS 使用 bundle name。其他系统操作请参阅[各平台预置 Node](./midscene-test/builtin-nodes)。

</GetStartedWhen>

<GetStartedWhen scene="test" platform="desktop">

- **测试自己的应用**：在被控制的显示器上打开目标应用，再用 `aiAct` 和 `aiAssert` 描述步骤。如需在用例中启动或重置应用，请[开发自定义 Node](./midscene-test/extend)。

</GetStartedWhen>

- **编写和组织用例**：[编写 YAML 用例](./midscene-test/writing)介绍了输入、变量、标签和 hooks。
- **在 CI 中运行**：请参阅[在 GitHub Actions 中运行](./midscene-test/running#在-github-actions-中运行)。

</GetStartedWhen>
