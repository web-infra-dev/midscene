## 用自然语言描述步骤与预期 {#test-intent}

按用户的操作意图写步骤，按用户看到的结果写预期。同一个测试意图，可以用 YAML 表达，也可以接入现有 JavaScript 测试。

## 为测试而生的 GUI Agent {#gui-agent}

Midscene 的 GUI Agent 为已有的 Playwright、Puppeteer 或 JavaScript 测试提供视觉操作与断言能力。

### 像人一样观察、操作并验证结果 {#visual-capabilities}

E2E 测试的初衷是从用户视角验证完整流程。Midscene 通过视觉模拟用户的操作方式：观察屏幕、找到目标、执行操作，再检查用户实际看到的结果。[查看实际案例](./showcases)

### 一套 API，覆盖不同平台 {#platforms}

视觉定位不依赖特定的界面渲染结构。各平台适配器提供截图和操作能力，让同一种交互方式覆盖 Web、移动端和桌面应用，也适用于 HTML canvas 等自定义界面。

## Midscene Test：全新的 E2E 测试框架 {#midscene-test}

Midscene Test（`@midscene/test`）是为自然语言设计的 E2E 测试框架。用例用自然语言描述操作与预期，业务逻辑写在 TypeScript Node 中，数据准备、清理、重试和测试报告由框架统一管理。[开始使用](./midscene-test/use)

### AI 操作与业务操作写在同一个用例里 {#ai-and-nodes}

每个 YAML 步骤调用一个 Node：AI 操作、平台操作或自定义业务操作。[框架概览](./midscene-test/overview)
