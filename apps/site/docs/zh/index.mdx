## 用视觉回归 E2E 测试的本质 {#why-vision}

E2E 测试要验证的是界面，不是代码结构。依赖 UI 代码结构的测试用例永远是脆弱的，更无法真正反映用户能不能顺利使用这个界面、界面的表达是否正确。

在 AI-native 的时代，模型让我们有能力回归测试的本质——直接看屏幕，像用户一样操作和判断。随着视觉模型的准确率与成本达到平衡，E2E 测试的下一个阶段已经到来。

## 用自然语言描述步骤与预期 {#test-intent}

按用户的操作意图写步骤，按用户看到的结果写预期。同一个测试意图，可以用 Midscene Test 写成 YAML，也可以接入现有 JavaScript 测试。

## 为视觉测试而生的 GUI Agent {#gui-agent}

如果你已有测试工程，Midscene 的 GUI Agent 可以直接为现有 JavaScript 测试提供视觉操作与断言能力。Web 场景推荐接入 [Playwright Test](./integrate-with-playwright)，移动端和桌面端推荐接入 [Rstest](./sdk/rstest) 或 [Vitest](./sdk/vitest)。
