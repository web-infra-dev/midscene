# HarmonyOS 环境配置

Midscene 通过 HarmonyOS Device Connector（HDC）连接并控制 HarmonyOS NEXT 设备，支持对原生应用、元服务及系统界面进行自动化操作。

本文介绍如何准备 HarmonyOS 环境：安装 HDC 并连接设备。Playground、Midscene Test 和 JavaScript SDK 都使用同样的连接。

## 验证 {#verify}

`hdc list targets` 输出目标设备 ID 后，在 Playground 中验证环境。打开[开始使用](../get-started?platform=harmonyos&scene=playground)，页面已为你选好 HarmonyOS 和 Playground，选择模型接入方式后，按步骤执行一次 `aiAct` 操作和一次 `aiAssert` 断言。断言通过即表示 HDC 连接、屏幕截图、触控输入和模型调用都正常。

## 常见问题

### 输入文本后键盘未收起，或页面意外返回

请参阅 [HarmonyOS JavaScript SDK](../sdk/harmonyos#输入文本后键盘未收起或页面意外返回)。

### 如何指定自定义的 HDC 路径？

可以通过 `HDC_HOME` 环境变量指定 `hdc` 所在的目录：

```bash
export HDC_HOME=/path/to/hdc/directory
```

通过代码参数传入的方式请参阅 [HarmonyOS JavaScript SDK](../sdk/harmonyos#如何指定自定义的-hdc-路径)。
