# HarmonyOS 环境配置

Midscene 通过 HarmonyOS Device Connector（HDC）连接并控制 HarmonyOS NEXT 设备，支持对原生应用、元服务及系统界面进行自动化操作。

本文介绍运行 Midscene Test、JavaScript SDK 和 Playground 所需的 HarmonyOS 环境配置。你可以先[通过 HDC 连接设备](#connect-device)，再使用 [Playground](#verify-in-playground) 验证屏幕截图、触控输入与模型调用。

## 通过 HDC 连接设备 {#connect-device}

运行 Midscene 的电脑需要通过 `hdc` 连接目标 HarmonyOS NEXT 设备。如果已安装 `hdc` 并连接好设备，可直接跳至[确认设备连接](#verify-device-connection)。

### 1. 安装 HDC

HDC（HarmonyOS Device Connector）是 HarmonyOS 官方提供的设备连接命令行工具，可通过以下任一方式安装：

- 通过 [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/) 安装（推荐）
- 下载 [HarmonyOS 命令行工具（Command Line Tools）](https://developer.huawei.com/consumer/cn/download/)独立安装

在终端运行以下命令，验证 `hdc` 是否安装成功：

```bash
hdc version
```

终端输出版本号即表示安装成功。

:::info 配置 HDC 路径

如果 `hdc` 未加入系统 `PATH`，可以通过设置 `HDC_HOME` 环境变量指向 `hdc` 所在的目录：

```bash
export HDC_HOME=/path/to/hdc/directory
```

:::

### 2. 开启调试并连接设备

1. 在 HarmonyOS 设备的系统设置中进入「系统 > 开发者选项」，开启 **USB 调试**。
2. 使用支持数据传输的 USB 数据线将设备连接到电脑。
3. 保持设备解锁亮屏，并在设备弹窗中允许 USB 调试授权。

### 3. 确认设备连接 {#verify-device-connection}

在终端运行以下命令检查连接状态：

```bash
hdc list targets
```

终端输出设备序列号（Device ID）即表示连接就绪：

```log
0123456789ABCDEF
```

如果同时连接了多台设备，请记录目标设备的序列号，以便后续在 Playground 或项目配置中指定该设备。若输出为空或显示 `[Empty]`，请检查 USB 数据线、连接模式、**USB 调试**开关及手机端的调试授权弹窗。

## 在 Playground 中验证 {#verify-in-playground}

借助 Playground，无需编写代码即可验证屏幕截图、触控输入与模型调用。

开始前，请参照[使用模型 API Key](../model-api-setup)或[使用 ChatGPT 订阅](../chatgpt-subscription)准备好模型配置。

### 启动 Playground

请确保已安装 Node.js（版本要求 `^20.19.0 || ^22.12.0 || >=24.0.0`），且终端中可正常执行 `node -v` 和 `npx --version`。

1. 在终端运行以下命令启动 HarmonyOS Playground：

```bash
npx --yes @midscene/harmony-playground
```

2. 在打开的 Playground 页面中，点击右上角的齿轮图标，粘贴模型配置并保存。
3. 若浏览器未自动打开，请手动访问终端打印的本地地址，并保持该终端进程持续运行。
4. 在左侧连接面板中选择目标 HDC 设备并创建 Agent（设备 ID 与 `hdc list targets` 的输出一致）。
5. 确认预览区域已正常显示当前手机屏幕画面；若画面未显示，请先排查 HDC 连接与设备调试授权。

### 执行操作并验证结果

在目标设备上打开系统浏览器，跳过首次启动引导，访问 [TodoMVC](https://todomvc.com/examples/react/dist/#/)，并保持设备处于解锁亮屏状态且浏览器位于前台。

1. 在 Playground 中选择 `aiAct`，输入以下指令并运行：

```text
添加一个名为“体验 Midscene”的待办事项，然后将它标记为已完成。
```

2. 待页面中出现已勾选完成的待办事项后，切换到 `aiAssert`，输入以下断言并运行：

```text
列表中存在名为“体验 Midscene”的待办事项，且它已被标记为完成。
```

3. 确认断言执行通过，并在结果面板中查看各步骤的截图与执行过程。至此，设备连接、屏幕截图、触控输入和模型调用均已验证完毕。

如果执行失败，请结合报错信息排查：若无画面或无法操控设备，请查看下方的[常见问题](#常见问题)；若模型请求报错，请参考[模型连接检查](../model-config#verify-model-connectivity)。

### 清理体验数据

验证结束后，请在 TodoMVC 页面中删除刚才创建的“体验 Midscene”待办事项。如果接下来要运行 Midscene Test 的 HarmonyOS 示例，请切换到 **All** 视图并确认列表已完全清空（包括已完成事项），因为示例模板在运行前会校验初始列表为空，且不会主动覆盖已有数据。

## 在测试或脚本中使用 {#use-in-project}

完成设备连接与 Playground 验证后，即可将设备接入你的测试或脚本项目：

| 已准备项 | 在项目中如何使用 |
| --- | --- |
| `HDC` 连接与调试授权 | 保持设备连接、解锁亮屏，并保留 USB 调试授权。 |
| 目标设备 ID | 在 Midscene Test 的 HarmonyOS 模板中通过 `HARMONY_DEVICE_ID` 指定，或在代码中通过 [HarmonyOS SDK](../sdk/harmonyos) 参数传入。 |
| 模型配置 | 写入项目的 `.env` 文件并按集成文档加载。Playground 中的设置仅保存在本地浏览器内，不会自动同步到项目中。 |

根据使用场景选择下一步：

- **使用 Midscene Test**：前往[配置模型与运行环境](../midscene-test/use#2-配置模型与运行环境)，完成配置并运行示例（若尚未初始化项目，可先从该页的[创建项目](../midscene-test/use#创建项目)开始并选择 HarmonyOS 平台）。
- **接入 JavaScript 测试框架**：参阅[接入 Vitest](../sdk/vitest)。
- **编写独立自动化脚本**：参阅[编写独立自动化脚本](../sdk/standalone)中的 HarmonyOS 示例。
- **查阅平台 SDK 接口**：阅读 [HarmonyOS JavaScript SDK](../sdk/harmonyos)，了解设备选择、构造参数、平台专属方法与生命周期管理。

## 常见问题

### 输入文本后键盘未收起，或页面意外返回

请参阅 [HarmonyOS JavaScript SDK](../sdk/harmonyos#输入文本后键盘未收起或页面意外返回)。

### 模型调用失败

请查看失败步骤的报错信息，并核对 Playground 设置或项目 `.env` 文件中的模型配置。设备连接正常并不代表模型服务可用，可参照[模型连接检查](../model-config#verify-model-connectivity)排查 API Key、服务地址或网络问题。注意，命令行与项目运行不会读取浏览器中保存的 Playground 配置，需单独加载项目的环境变量。

## 高级连接与调试

### 如何指定自定义的 HDC 路径？

可以通过 `HDC_HOME` 环境变量指定 `hdc` 所在的目录：

```bash
export HDC_HOME=/path/to/hdc/directory
```

通过代码参数传入的方式请参阅 [HarmonyOS JavaScript SDK](../sdk/harmonyos#如何指定自定义的-hdc-路径)。
