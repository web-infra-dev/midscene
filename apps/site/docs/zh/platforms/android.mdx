# Android

Midscene 通过 `adb` 连接并控制 Android 设备，支持对原生应用、混合应用及系统界面进行自动化操作。

本文将带你完成 Android 环境准备与设备连接，并在 Playground 中试跑一次操作与断言，为后续接入测试框架或 JavaScript SDK 做好准备。

## 快速开始

请先安装 Node.js（版本要求 `^20.19.0 || ^22.12.0 || >=24.0.0`），确认终端中可执行 `node -v` 和 `npx --version`，并提前准备好[模型配置](../model-api-setup)（稍后将在 Playground 中填写）。

### 准备 Android 设备

开始前，请确保本机 `adb` 能够正常识别并连接目标 Android 设备。

#### 1. 安装 `adb` 并配置 `ANDROID_HOME`

- 通过 [Android Studio](https://developer.android.com/studio) 或独立的 [Android 命令行工具](https://developer.android.com/studio#command-line-tools-only)安装 `adb`。
- 在终端验证 `adb` 是否安装成功：

```bash
adb --version
```

输出类似以下内容即表示安装成功：

```log
Android Debug Bridge version 1.0.41
Version 34.0.4-10411341
Installed as /usr/local/bin/adb
Running on Darwin 24.3.0 (arm64)
```

- 参考 [Android 环境变量文档](https://developer.android.com/tools/variables)配置 `ANDROID_HOME` 环境变量，并验证是否生效：

```bash
echo $ANDROID_HOME
```

输出应指向实际安装的 Android SDK 目录，例如：

```log
/Users/your_username/Library/Android/sdk
```

#### 2. 开启 USB 调试并验证连接

在手机系统设置的「开发者选项」中开启 **USB 调试**（如果存在 **USB 调试（安全设置）**，也请一并开启），然后通过 USB 数据线将手机连接到电脑。

<p align="center">
  <img src="/images/android-usb-debug-en.png" alt="android usb debug" width="400"/>
</p>

在终端运行以下命令验证设备连接：

```bash
adb devices -l
```

输出类似以下内容即表示连接成功：

```log
List of devices attached
s4ey59	device usb:34603008X product:cezanne model:M2006J device:cezan transport_id:3
```

排查提示：
- 若列表为空：请检查数据线是否支持数据传输、手机 USB 连接模式及开发者选项开关；
- 若状态显示为 `unauthorized`：请解锁手机屏幕，在手机弹出的授权窗口中勾选并允许 USB 调试；
- 若状态显示为 `offline`：请重新插拔数据线或重启 `adb`。只有当设备状态显示为 `device` 时，才可继续后续步骤。

### 启动 Playground

无需编写代码，即可通过 Playground 快速验证设备截图、触控输入与模型调用是否正常：

1. 在终端运行以下命令启动 Android Playground：

```bash
npx --yes @midscene/android-playground
```

2. 在自动打开的 Playground 页面中，点击右上角的齿轮图标，粘贴你的模型 API Key 配置并保存（配置格式见[配置模型 API Key](../model-api-setup)）。

![](/images/android-set-env.png)

3. 若浏览器未自动打开，请手动访问终端打印的本地地址，并保持该终端窗口持续运行。
4. 在左侧连接面板中选择目标 **ADB device** 并创建 Agent（若连接了多台设备，可对照 `adb devices -l` 输出的设备 ID 进行选择）。
5. 确认预览区域已正常显示当前手机屏幕画面；若画面未显示，请先排查设备连接与截屏权限。

### 执行操作并验证结果

在手机上打开系统浏览器，跳过首次启动引导，访问 [TodoMVC](https://todomvc.com/examples/react/dist/#/)，并保持手机处于解锁亮屏状态且浏览器位于前台。

1. 在 Playground 中选择 `aiAct`，输入以下指令并运行：

```text
添加一个名为“体验 Midscene”的待办事项，然后将它标记为已完成。
```

2. 待页面中出现已勾选完成的待办事项后，切换到 `aiAssert`，输入以下断言并运行：

```text
列表中存在名为“体验 Midscene”的待办事项，且它已被标记为完成。
```

3. 确认断言执行通过，并在结果面板中查看各步骤的截图与执行过程。至此，设备连接、屏幕截图、触控输入和模型调用均已验证完毕。

如果执行失败，请结合报错信息排查：若无画面或无法操控设备，请查看下方的「常见问题」；若模型请求报错，请参考[模型连接检查](../model-config#verify-model-connectivity)。

## 下一步

完成环境与 Playground 验证后，可根据使用场景选择接入方式：

- **编写 YAML 测试**：通过 [Midscene Test](../midscene-test/use) 初始化项目、运行测试用例并查看报告。
- **接入现有 JavaScript 测试**：[接入 Vitest](../sdk/vitest)。
- **编写独立自动化脚本**：阅读[编写独立自动化脚本](../sdk/standalone)，参考对应平台的完整代码示例。
- **查阅平台 SDK 接口**：阅读 [Android JavaScript SDK](../sdk/android)，了解构造参数、平台专属方法与生命周期管理。

注意：在 Playground 界面中填写的模型配置仅保存在本地浏览器中，不会自动同步到测试或脚本进程。接入工程时，请将验证通过的模型配置写入项目的 `.env` 文件并按文档说明加载，同时保持 `adb` 连接与设备调试权限处于可用状态。

## 常见问题

### 设备已连接，为什么仍然无法控制（报错 `INJECT_EVENTS`）？

如果执行点击或滑动时遇到类似以下的权限报错：

```text
Error:
Exception occurred while executing 'tap':
java.lang.SecurityException: Injecting input events requires the caller (or the source of the instrumentation, if any) to have the INJECT_EVENTS permission.
```

这通常是因为部分品牌手机（如小米 / Redmi / VIVO / OPPO 等）对模拟点击有独立的权限开关。请在系统设置的「开发者选项」中确认以下两项均已开启：

1. **USB 调试**
2. **USB 调试（安全设置）** 或 **禁止权限监控**（如有）

### 为什么 scrcpy 会回退到 ADB 截图？

为避免模型基于过期画面做出错误决策，Midscene 会严格校验 scrcpy 视频帧的时间戳：任何无法证明采集时间晚于最近一次已完成操作、或超出最大帧龄限制的视频帧都会被拒绝。如果当前 scrcpy 视频流未能及时提供有效新帧，Midscene 会自动重启一次 scrcpy；仅当重启后仍无法获取有效帧时，才会回退为 `adb` 截图。

部分 Android 硬件编码器在屏幕画面完全静止时会暂停输出新帧，或者在视频流刚启动、USB 传输抖动时也可能触发该现象。注意：出现帧新鲜度超时告警并不代表传输带宽不足或视频码率过高，请勿仅因看到该告警就盲目调整视频码率。

### 如何从局域网其他电脑远程访问 Android Playground？

出于安全考虑，Playground 服务与内置的 scrcpy 投屏服务默认均只监听本机回环地址 `127.0.0.1`。如果需要从局域网内的另一台电脑访问 Android Playground，需在启动时通过环境变量显式放开两者的监听地址（以 macOS / Linux 为例）：

```bash
MIDSCENE_PLAYGROUND_HOST=0.0.0.0 MIDSCENE_SCRCPY_HOST=0.0.0.0 pnpm dlx @midscene/android-playground
```

启动后，在客户端浏览器中访问服务端电脑的实际局域网 IP（或主机名）加上终端打印的 Playground 端口（注意：`0.0.0.0` 是服务端监听通配地址，不能直接填在浏览器地址栏中），并确保防火墙已放行 Playground 与 scrcpy 两个端口。

`MIDSCENE_SCRCPY_HOST` 仅作用于独立的 Android Playground CLI，也可直接设为服务端具体的网卡 IP（如 `192.168.1.100`，此时本机自动打开的预览页也会使用该 IP 连接投屏流）。若在代码中直接实例化 `ScrcpyServer`，可通过构造函数参数 `host` 指定监听地址。

:::warning 安全提示
scrcpy 投屏服务目前不包含会话鉴权机制。开启远程监听后，任何能够访问该端口的客户端均可读取设备信息与实时屏幕画面。请仅在受信任的内网环境中开启，并通过防火墙限制可访问的客户端范围。
:::
