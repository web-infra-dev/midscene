# 平台环境配置

Midscene 支持通过 Chrome Bridge 控制已有浏览器，也支持移动设备、HarmonyOS 设备和桌面应用。请根据目标界面和连接方式选择平台。

Midscene 使用多模态视觉模型理解截图，因此自动化过程面向最终呈现的界面，不依赖底层 UI 结构。同一套方法可以适配原生应用和跨平台技术栈。

## 选择平台

| 平台 | npm 包 | 连接方式 | 典型用途 |
| --- | --- | --- | --- |
| [Chrome Bridge](../bridge-mode) | `@midscene/web` | Chrome 插件 | 复用桌面 Chrome 的登录状态与标签页 |
| [Android](./android) | `@midscene/android` | adb | Android App 和系统界面 |
| [iOS](./ios) | `@midscene/ios` | WebDriverAgent | iOS App 和系统界面 |
| [HarmonyOS](./harmonyos) | `@midscene/harmony` | HDC | HarmonyOS NEXT App 和系统界面 |
| [桌面端](./desktop) | `@midscene/computer` | 原生输入或 RDP | Windows、macOS 和 Linux 应用 |

平台指南介绍环境准备和连接故障排查，并提供连接验证或 Playground 体验。

如果需要构造函数选项、平台专属方法或通用 Agent API，请阅读 [API 参考](../reference/index.mdx)。

移动端和桌面端的 JavaScript 测试推荐[接入 Vitest](../sdk/vitest)。不使用测试框架的流程请参阅[独立自动化脚本](../sdk/standalone)。
