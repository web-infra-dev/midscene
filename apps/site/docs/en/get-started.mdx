# Get started

A first run needs three things: the target browser or device, a way to use Midscene, and a model. Answer the questions below to get the steps for your combination. Each path ends with a successful action and assertion that you can inspect.

The page URL keeps your answers, so you can bookmark or share a path.

## Install the Chrome extension

1. Install Midscene from the Chrome Web Store:

   <ChromeExtensionButton linkLabel="Install the Midscene extension from the Chrome Web Store" />

2. Open **Midscene** from the Chrome extensions list. The Midscene sidebar appears on the right side of the browser.

<GetStartedStep id="test-configure">

## Configure the project

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

<GetStartedWhen model="api-key">

Fill in the four `MIDSCENE_MODEL_*` values with the configuration you prepared.

</GetStartedWhen>

<GetStartedWhen model="chatgpt">

Leave `MIDSCENE_MODEL_BASE_URL` and `MIDSCENE_MODEL_API_KEY` empty. Set `MIDSCENE_MODEL_NAME` and `MIDSCENE_MODEL_FAMILY`, and add `MIDSCENE_MODEL_AUTH_MODE`:

```bash
MIDSCENE_MODEL_AUTH_MODE="siwc"
MIDSCENE_MODEL_NAME="gpt-6-sol"
MIDSCENE_MODEL_FAMILY="gpt-6"
```

</GetStartedWhen>

Verify model connectivity and Midscene compatibility. The command reads `.env` from the current directory and does not need a browser or device:

```bash
pnpm exec midscene-test model verify
```

If the check fails, see [Verify model connectivity](./model-config#verify-model-connectivity).

<GetStartedWhen platform="web">

Install Chromium for Playwright:

```bash
pnpm exec playwright install chromium
```

</GetStartedWhen>

<GetStartedWhen platform="android">

If more than one device is connected, set `ANDROID_DEVICE_ID` in `.env` to an ID from `adb devices -l`.

</GetStartedWhen>

<GetStartedWhen platform="ios">

The project connects to WDA on `localhost:8100` by default. For another address, set `WDA_HOST` and `WDA_PORT` in `.env`, or `WDA_BASE_URL` when you connect through a gateway.

</GetStartedWhen>

<GetStartedWhen platform="harmonyos">

If more than one device is connected, set `HARMONY_DEVICE_ID` in `.env` to an ID from `hdc list targets`. If `hdc` is not on `PATH`, set `HDC_HOME`.

</GetStartedWhen>

<GetStartedWhen platform="desktop">

To control a display other than the primary one, set `COMPUTER_DISPLAY_ID` in `.env`. On headless Linux, also set `MIDSCENE_COMPUTER_HEADLESS_LINUX=true`.

</GetStartedWhen>

</GetStartedStep>

<GetStartedStep id="test-run">

## Run the example and inspect the report

<GetStartedWhen platform="web">

The example opens React TodoMVC in Chromium, seeds three todos, and changes them with `aiAct` and `aiAssert`.

</GetStartedWhen>

<GetStartedWhen platform={['android', 'ios', 'harmonyos']}>

The example opens React TodoMVC in the device's browser and first checks that the list is empty. Keep the device unlocked. If todos remain from an earlier run, select **All** and delete every todo, including completed ones.

</GetStartedWhen>

<GetStartedWhen platform="desktop">

The example opens React TodoMVC in a browser on the target display and first checks that the list is empty. Do not move the mouse or type while it runs. If todos remain from an earlier run, select **All** and delete every todo, including completed ones.

</GetStartedWhen>

```bash
pnpm test
```

The terminal prints the results and a `Report:` path. Open the HTML report, then select a case and a step to inspect screenshots, inputs, outputs, and errors. Reports are written to `midscene_run/report/` by default.

When the case passes, your model, environment, and project are all working. For execution options, see [Run tests](./midscene-test/running).

</GetStartedStep>

## Next steps

<GetStartedWhen scene="playground">

- **Write tests**: Change your answer to **What do you want to do first?** and choose **Create a Midscene Test project** or **Add to a JavaScript test project**. Settings entered in Playground are stored by the browser and are not shared with projects.
- **Understand the APIs you just used**: Read [The basics](./basics).

</GetStartedWhen>

<GetStartedWhen scene="test" platform="web">

- **Test your own site**: In `cases/todo.yaml`, replace the TodoMVC setup in `beforeEach` with a `gotoUrl` Node for your URL, then describe the steps with `aiAct` and `aiAssert`. See [Built-in Nodes across platforms](./midscene-test/builtin-nodes).

</GetStartedWhen>

<GetStartedWhen scene="test" platform={['android', 'ios', 'harmonyos']}>

- **Test your own app**: In `cases/todo.yaml`, replace the TodoMVC setup in `beforeEach` with a `launch` Node that opens your app:

  ```yaml
  beforeEach:
    - launch: com.example.app

  cases:
    - name: Open the home screen
      steps:
        - aiAssert: The home screen of the app is visible
  ```

  Use the package name on Android, the bundle identifier on iOS, or the bundle name on HarmonyOS. See [Built-in Nodes across platforms](./midscene-test/builtin-nodes) for other system operations.

</GetStartedWhen>

<GetStartedWhen scene="test" platform="desktop">

- **Test your own app**: Open the target application on the controlled display, then describe the steps with `aiAct` and `aiAssert`. To start or reset the app from a case, [develop a custom Node](./midscene-test/extend).

</GetStartedWhen>

<GetStartedWhen scene="test">

- **Write and organize cases**: [Write YAML cases](./midscene-test/writing) covers inputs, variables, tags, and hooks.
- **Run in CI**: [Run in GitHub Actions](./midscene-test/running#run-in-github-actions).

</GetStartedWhen>

<GetStartedWhen scene="sdk">

- **Look up APIs**: [API reference](./reference/) lists every Agent method and its options.
- **Combine AI calls with code**: [Key APIs](./basics#javascript-orchestration) explains when to use `aiAct`, instant actions, and insight APIs.

</GetStartedWhen>
