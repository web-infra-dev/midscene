## A new E2E testing framework designed for natural language {#midscene-test}

Midscene Test (`@midscene/test`) is designed from the ground up for natural-language E2E testing. Write actions and assertions in YAML, extend test steps with TypeScript Nodes, and manage setup, cleanup, retries, and execution reports within one framework. [Get started with Midscene Test](./midscene-test/use)

### AI steps and Nodes in one YAML file {#ai-and-nodes}

Organize tests in YAML so people and AI agents can read, write, and review natural-language intent alongside code steps.

### Customize your test project {#nodes-and-spec}

Extend Midscene Test with TypeScript Nodes for your business operations. Register them to make them callable from YAML, then generate a Markdown Node Spec describing the available operations and their inputs. People and AI agents can use the Spec to reference these Nodes in test cases. [Develop custom Nodes](./midscene-test/extend)
