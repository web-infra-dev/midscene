# Midscene AppControlBench Benchmark Report

import { AppControlBenchReport } from '@theme';

This report presents Midscene results on the AppControlBench benchmark. The evaluation covers 60 iOS tasks, with a **Pass@1 score of 96.67% (58/60)** and a **completion score of 96.67%** (58 success, 0 partial, and 2 fail). The recorded model cost for the complete run is **$0.6077 / ¥4.1326**.

:::info About AppControlBench

[AppControlBench](https://github.com/software-mansion/app-control-bench) evaluates how well an Agent can operate real iOS apps in isolated Simulator runs. Each task starts from fresh device and server state, and the final screenshot is graded against a task-specific solved-screen description. This run covers 30 Bluesky tasks and 30 Element iOS tasks.

:::

## Case Intent Calibration

For this evaluation, the action-route descriptions of 2 cases were calibrated against the actual UI of the pinned Element iOS version. The calibration only removes stale or unavailable UI-entry descriptions; it does not change the final target state or judge rules of either case.

| Case | Intent calibration | Evaluation target |
| --- | --- | --- |
| `element-06` | Replaced the old-version “+ button” route with the current create/compose entry used to open the create-room menu. | The same create/compose menu popover is open on “All chats”. |
| `element-07` | Replaced the unavailable header `...` route with opening Room Info/options through the room title, avatar, or header. | The same Project Phoenix Room Info/options screen is open. |

## Model cost calculation

Each task price comes from the `usage` and `searchAreaUsage` recorded in its Midscene execution report. For `doubao-seed-2-1-turbo-260628`, the report uses the standard inference rates of ¥3 per million non-cached input tokens, ¥0.6 per million cached input tokens, and ¥15 per million output tokens. USD values use an exchange rate of ¥6.8 per $1.

The values below cover Midscene execution model calls only; AppControlBench judge calls and cache-storage charges are excluded. Per-task calculations are stored to six decimal places and displayed to four decimal places.
