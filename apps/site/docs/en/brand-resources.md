# Brand resources

This page provides the official Midscene.js icon and brand color for documentation, integrations, and badges.

## Icon

- [Monochrome SVG](/images/brand/midscenedotjs.svg)
- [Color icon](/images/brand/midscene-icon.png)
- [All brand assets on GitHub](https://github.com/web-infra-dev/midscene/tree/main/apps/site/docs/public/images/brand)

The monochrome SVG uses a 24 × 24 viewBox and a single compound path. It has a transparent background and no explicit fill color, so it defaults to black. Set the fill color when rendering it.

## Brand color

The Midscene.js brand color is dark gray:

| Format | Value |
| --- | --- |
| HEX | `#3F464C` |
| RGB | `63, 70, 76` |

This is the outline color of the color logo. Use `3F464C` when an icon library requires a six-digit hexadecimal value without the hash.

For monochrome presentations, use the brand color on a light background or white on a dark background. Preserve the icon's proportions.
