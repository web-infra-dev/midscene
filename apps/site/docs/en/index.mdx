# See interfaces like a human<br />E2E testing in natural language

<div className="introduction-page">

Midscene.js provides a vision-based GUI Agent and a natural-language E2E testing framework for web, mobile, and desktop apps.

**🔥 Latest news** Starting with v1.16, Midscene supports using Jev 1.4’s visual capabilities to drive E2E testing. [See what’s new](./changelog#v1160)

## A GUI Agent built for testing {#gui-agent}

Midscene’s GUI Agent brings visual actions and assertions to your existing JavaScript tests. We recommend [Playwright Test](./integrate-with-playwright) for web apps and [Vitest](./sdk/vitest) for mobile and desktop apps.

### One API, across platforms {#platforms}

Visual localization does not depend on a particular UI rendering stack. Platform adapters provide screenshots and actions, bringing the same approach to web, mobile, and desktop interfaces, including HTML canvas.
