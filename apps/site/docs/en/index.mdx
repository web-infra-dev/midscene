## A GUI Agent built for testing {#gui-agent}

Midscene’s GUI Agent brings visual actions and assertions to your existing Playwright, Puppeteer, or JavaScript tests.

### See, act, and verify like a human {#visual-capabilities}

E2E testing aims to verify complete workflows from the user’s perspective. Midscene uses vision to interact as a user would: observe the screen, find the target, act, and check what the user actually sees. [See real-world examples](./showcases)

### One API, across platforms {#platforms}

Visual localization does not depend on a particular UI rendering stack. Platform adapters provide screenshots and actions, bringing the same approach to web, mobile, and desktop interfaces, including HTML canvas.

## Midscene Test: a new E2E testing framework {#midscene-test}

Midscene Test (`@midscene/test`) is an E2E testing framework designed for natural language. Cases describe actions and expectations in natural language, business logic lives in TypeScript Nodes, and the framework manages setup, cleanup, retries, and reports. [Get started](./midscene-test/use)

### AI and business operations in one case {#ai-and-nodes}

Each YAML step calls a Node: an AI operation, a platform operation, or a custom business operation. [Framework overview](./midscene-test/overview)

### Custom Nodes and Node Spec {#nodes-and-spec}
