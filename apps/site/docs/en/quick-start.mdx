# Try the GUI Agent

Use the Chrome extension to try the GUI Agent in a browser Playground without setting up a test project. This guide walks you through model configuration, running a natural-language instruction, checking its result, and reviewing execution.

To write YAML tests directly, go to [Midscene Test](./midscene-test/use). For mobile and desktop Playgrounds, see [other platforms](#use-midscene-on-other-platforms).

## Configure a model

Before using the Chrome extension, prepare a multimodal model with UI localization capabilities. If you have not chosen a model or connection method, start with the [Model Selection Guide](./model-selection).

<SetupEnv />

If you use a ChatGPT subscription, follow [Use a ChatGPT subscription](./chatgpt-subscription) to obtain the complete model configuration, then continue with extension installation. Choose either connection method.

After installing the Chrome extension, paste this configuration into its settings.

## Install the Chrome extension {#chrome-extension}

1. Use the button below to install Midscene from the Chrome Web Store:

   <ChromeExtensionButton linkLabel="Install the Midscene extension from the Chrome Web Store" />

2. Open **Midscene** from the Chrome extensions list. The Midscene sidebar appears on the right side of the browser.
3. Click the settings icon in the sidebar, paste the complete configuration from [Configure a model](#configure-a-model), and save it.

## Perform an action and check the result

Open the [TodoMVC example](https://todomvc.com/examples/react/dist/#/), keep the page visible, and try the following API categories in the Midscene sidebar.

### 1. Complete a goal (`aiAct`)

Select `aiAct`, then enter and run:

```text
Add a todo named "Try Midscene", then mark it as completed.
```

The Agent observes the page, finds the input, adds the todo, and checks it off. When execution finishes, you should see the todo marked as completed.

### 2. Check the result (`aiAssert`)

Select `aiAssert`, then enter and run:

```text
The list contains a todo named "Try Midscene", and it is marked as completed.
```

The assertion passes if the condition is true. Otherwise, the result shows an error with the model's reason.

### 3. Extract data (`aiQuery`, optional)

Select `aiQuery`, then enter and run:

```text
Visible todos in the list, return {name: string, completed: boolean}[].
```

The result contains todo names and completion states. The same interface can be operated, checked, and read.

## Review execution

After running an instruction, inspect the steps and screenshots in the Playground's result area and compare them with the final page state. If execution fails, inspect the failed step and error first. For model connection issues, see [Model advanced configuration and debugging](./model-config#verify-model-connectivity).

## Troubleshooting

<span id="chrome-extension-faq" />

<details>
<summary>Can I install the Chrome extension manually?</summary>

If you cannot access the Chrome Web Store, download the installation package from the [GitHub Releases page](https://github.com/web-infra-dev/midscene/releases) and install it manually. Manual installations do not receive automatic updates.

</details>

<details>
<summary>It fails with `Cannot access a chrome-extension:// URL of different extension`</summary>

This error usually indicates a conflict between Midscene and another Chrome extension. For example, another Chrome extension may have injected an `<iframe />` or `<script />` into the page.

Follow these steps to find the conflicting Chrome extension:

1. Open the page's developer tools, find an `<iframe />` or `<script />` whose URL starts with `chrome-extension://`, and copy the extension ID from the URL.
2. Open `chrome://extensions/`, find the Chrome extension by its ID, and disable it.
3. Refresh the page and try again.

</details>

<details>
<summary>I get a 403 error when using an Ollama model</summary>

Set the `OLLAMA_ORIGINS="*"` environment variable to allow the Chrome extension to access the Ollama model.

</details>
