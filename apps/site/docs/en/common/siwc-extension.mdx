1. In the Midscene sidebar, click the settings icon to open the model configuration dialog, then click **Use your ChatGPT plan** and follow the on-screen instructions to sign in and authorize plan usage.
2. Paste the following configuration into the same dialog:

```bash
MIDSCENE_MODEL_AUTH_MODE="siwc"
MIDSCENE_MODEL_NAME="gpt-6-sol"
MIDSCENE_MODEL_FAMILY="gpt-6"
```

3. Click **Verify** to test the connection. For failed checks, see [Model advanced configuration and debugging](../model-config#verify-model-connectivity).
