Midscene Test (`@midscene/test`) is a natural-language E2E testing framework. In a single YAML case, you can describe UI actions and expected outcomes in natural language while encapsulating business logic that requires precise control in TypeScript. Cases have a clear, readable structure that both people and AI agents can write and maintain, allowing test intent and underlying implementation to evolve independently.
